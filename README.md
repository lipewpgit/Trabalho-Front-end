# Atividade 3 — Stats preview card

Projeto em HTML e CSS, pronto para abrir no VS Code. Não precisa instalar dependências.

## Como abrir

Abra esta pasta no VS Code e abra `index.html` no navegador. Se preferir, use a extensão Live Server. Preserve as pastas `images` e `fonts` junto dos arquivos HTML e CSS.

## Arquivos

- `index.html`: conteúdo e estrutura do card.
- `style.css`: fontes, cores e layouts responsivos.
- `images/pessoas.jpg`: imagem mobile enviada pelo usuário.
- `images/pessoas-desktop.jpg`: enquadramento desktop da mesma foto, obtido no repositório original.
- `images/favicon-32x32.png`: favicon enviado pelo usuário.
- `fonts/`: Inter 400/700 e Lexend Deca 400, com suas licenças. As fontes são locais para funcionar também offline.
- `references/pc.jpg` e `references/mob.jpg`: referências enviadas pelo usuário.
- `style-guide.md`: guia original da atividade.

## Responsividade

As referências usam 1440 × 800 px no desktop e 375 × 956 px no mobile. O guia especifica as larguras dos designs, mas não um breakpoint obrigatório. O layout muda para duas colunas a partir de 800 px. Abaixo disso, a imagem fica no topo e as estatísticas ficam em coluna. O conteúdo permanece acessível por rolagem quando a tela é mais baixa que o card.

Fonte da atividade e dos arquivos complementares: [ADS-Unipar/desafios-frontend](https://github.com/ADS-Unipar/desafios-frontend/tree/main/stats-preview-card-component-main).
